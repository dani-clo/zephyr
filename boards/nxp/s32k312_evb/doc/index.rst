.. zephyr:board:: s32k312_evb

Overview
********

NXP S32K312EVB-Q172 is an evaluation board based on the NXP S32K312 MCU.
The board support is initially derived from the existing S32K344-based Zephyr
support and is intended to build the basic Zephyr samples.
